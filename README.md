# LangChain Chatbot

A simple AI-powered chatbot built using **Python, LangChain, OpenAI API, and Streamlit**. It allows users to enter queries and receive AI-generated responses through a web interface.

## Features

- Interactive chatbot interface.
- AI-generated responses using OpenAI.
- LangChain integration.
- Secure API key management using environment variables.

## Tech Stack

- Python
- LangChain
- OpenAI API
- Streamlit
- python-dotenv
